# rcf-dr-rsi

Code for the paper **"Robust Off-Policy Inference and Policy Selection for Replay-Based Recursive
Self-Improvement."**

The main estimator is **RCF-DR-VR-SN**. It is a cross-fitted doubly robust (DR) off-policy value estimator with:
- a Huber residual threshold τ_n = 0.5·MAD(r)·n^{1/4};
- a weight cap c_n = w̄·√(n / log n);
- one-step rescaling;
- self-normalisation of the correction term.

The repository contains exactly the code used for the three empirical components of the paper: the simulation
study, the ASlib application and the KuaiRec application. It also contains the shared estimators and overlap
diagnostics.

## Installation

```
git clone https://github.com/<user>/rcf-dr-rsi.git
cd rcf-dr-rsi
python -m venv .venv && . .venv/bin/activate      # Python 3.11 was used
pip install -r requirements.txt                    # or: conda env create -f environment.yml
pytest tests/                                      # 15 unit tests, < 10 s
```

All commands are run from the repository root with `python -m ...`. No installation step or `PYTHONPATH` is
needed.

## Reproducing the paper

| Component | Command | Time (2 cores) |
|---|---|---|
| Simulation runs | `sh scripts/run_simulations.sh` | ≈ 2.5 h |
| Simulation figures and tables | `sh scripts/make_simulation_outputs.sh` | ≈ 2 min |
| ASlib (needs `data/aslib/aslib_data`) | `sh scripts/run_aslib.sh` | ≈ 2 h |
| KuaiRec (needs `data/kuairec/reduced`) | `sh scripts/run_kuairec.sh` | ≈ 20 min |

`REPRODUCIBILITY.md` maps every figure and table of the paper and supplement to its script and input files, and
lists all seeds.

The summary tables of the final runs are included under `results/`. With them, all LaTeX tables can be
regenerated without rerunning anything. The saved raw replications are distributed separately; place them in
`results/*/raw/`. `python -m tests.verify_against_saved` then re-runs selected replications and checks that they
reproduce the saved estimates.

## Using the estimator on new data

```python
from src.registry import REAL_DATA_ESTIMATORS
from src.diagnostics import overlap_diagnostic

fn, kw = REAL_DATA_ESTIMATORS["RCF-DR-VR-SN"]
# pi, pbhat, mhat: n x K arrays (target probs, logging probs, reward-model predictions); A: actions; Y: rewards
value, se, diag = fn(pi, A, Y, mhat, pbhat, return_diag=True, **kw)
w = pi[range(len(A)), A] / pbhat[range(len(A)), A]
print(value, se, overlap_diagnostic(w)["category"])     # warn when "non-root-n"
```

The method is intended for continuous, non-degenerate rewards. With sparse binary rewards, the MAD-based residual
threshold can collapse.
