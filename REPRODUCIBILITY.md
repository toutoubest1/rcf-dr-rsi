# Reproducibility map

This file maps every figure and table of the paper and the supplement to the script that generates it and to
the saved outputs it reads. Commands are run from the repository root. Numbering follows the compiled manuscript:
main text Figures 1–7 and Tables 1–6; supplement Figures S1–S6 and Tables S1–S42.

## Pipeline levels

There are three levels, each starting from the output of the previous one.

1. **Raw replications.**
   - **Scripts:** `scripts/run_simulations.sh`, `scripts/run_aslib.sh`, `scripts/run_kuairec.sh`.
   - **Output:** `results/{simulation,aslib,kuairec}/raw/`.
   - **Seeds and settings:** the exact final ones.
   - **Runtime (2 cores):** about 2.5 h, 2 h and 20 min.
2. **Summaries.**
   - **Scripts:** `experiments.analyze_final`, `real_data.aslib.analyze_aslib`, `real_data.kuairec.analyze_kuairec`.
   - **Output:** `results/*/tables/`. These summary files are **included in the repository**.
3. **Paper figures and LaTeX tables.**
   - **Scripts:** `experiments.make_paper_tables`, `real_data.aslib.make_tables`, `real_data.kuairec.make_tables`
     and `real_data.kuairec.make_main_figure`, together with the figure functions of the analysis scripts.
   - **Output:** `figures/`, `tables/` and `supp_tables/`. These are **included in the repository**.

The saved raw replication files (about 160 MB) are too large for the Git repository. They are distributed
separately, for example as a release asset (`raw_results_*.zip`), and unpack into `results/*/raw/`.

- **With the raw files:** every figure and table can be regenerated without rerunning any simulation.
- **Without them (fresh clone):** level 3 still works from the included summaries for every LaTeX table except
  Table S39, and for Figure 7 and Figures S5–S6. `real_data.kuairec.make_tables` prints a notice and skips
  Table S39 and Figure S4. Figures 1–6 and S1–S4, Table S39, `experiments.analyze_final`,
  `experiments.threshold_rates summary` and `tests.verify_against_saved` read individual replications, so they
  need the raw files or a rerun of level 1. The committed copies of those figures are in `figures/`.

## Verification performed for this release

The repository code was run against the saved results of the original runs.

- `python -m tests.verify_against_saved` re-runs selected replications, recomputes their estimates and compares
  them with the saved ones. The selection covers:
  - the IID grid;
  - M = 20 selection;
  - adaptive logging with K-fold, forward and forward-strict fitting;
  - contamination;
  - the h-logger;
  - AR(1) covariates;
  - the threshold-rate ablation;
  - the ASlib and KuaiRec pipelines.

  Maximum difference: at most 5e-16 for the simulations (CSV rounding) and exactly 0 for ASlib and KuaiRec.
- Regenerating from the saved raw files reproduces every simulation figure (Figures 1–5, S1) **pixel-identically**,
  and every simulation LaTeX table **byte-identically**.
- The ASlib figures, the KuaiRec LaTeX tables and the KuaiRec figures are reproduced identically.
- The design files (`design_*.json`, `policy_truth_*.csv`) and the data audits are reproduced exactly.
- `pytest tests/` passes (15 unit tests).

## Naming differences from the development code

The development tags `adaptdiag_r3` and `rates_r3_n*` are kept as file names so that the saved outputs match.

In the saved `rates_r3_n*` files, the development estimator names were renamed to the final names, and only the
four estimators reported in the supplement were kept:
- `VR-n14` became `RCF-DR-VR`;
- `VR-n13` became `RCF-DR-VR-n13`.

All other estimates are unchanged.
